# FileServerLocalAPI

When you need to access files in your hard drive from a browser with access to the same hard drive (as browsers usually block direct file access).

## Environment setup

Create in the root folder a file called `.env` with the following content:

```
PORT=80
HOST=localhost
SECRET=swordfish
```

Change `PORT`'s value by a free port in your system.

Change `SECRET`'s value by a value that is used by JWT to sign the tokens generated by this API.

***Don't add this file to source control!***
